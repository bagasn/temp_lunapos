# L10n (Localization) Rules

## Mandatory Usage
- **WAJIB** menggunakan `AppLocalizations.of(context)!` (dialiaskan `l10n`) untuk **semua** teks yang tampil ke pengguna.
- **DILARANG** menggunakan hardcoded string dalam widget, misalnya:
  - ❌ `Text('Simpan')`
  - ✅ `Text(l10n.btnSave)`

## Cara Mengakses L10n
Selalu buat alias lokal `l10n` di dalam fungsi `build`:
```dart
@override
Widget build(BuildContext context) {
  final l10n = AppLocalizations.of(context)!;
  return Text(l10n.btnSave);
}
```

## Konvensi Penamaan Key ARB
Key ARB menggunakan format **`prefix_camelCase` berbahasa Inggris**, mengikuti pola yang sama seperti project referensi (LunaposDashboard):

| Prefix | Kategori | Kapan digunakan | Contoh Key | Contoh Nilai |
|---|---|---|---|---|
| `title_` | Judul halaman | Heading/title utama sebuah halaman atau dialog | `title_orderList` | `"Daftar Order"` |
| `lbl_` | Label | Teks label dengan *WordCapitalize* (huruf besar tiap kata) | `lbl_transactionDate` | `"Tanggal Transaksi"` |
| `txt_` | Text | Teks biasa tanpa aturan kapitalisasi khusus | `txt_welcomeBack` | `"Selamat datang kembali!"` |
| `btn_` | Button | Teks pada tombol — dipisah dari `lbl_`/`txt_` karena bisa berbeda pengucapan antar bahasa | `btn_save` | `"Simpan"` |
| `err_` | Error message | Pesan error atau validasi | `err_invalidEmail` | `"Alamat email tidak valid"` |
| `desc_` | Description | Kalimat panjang agar key tidak terlalu panjang | `desc_forgotPassword` | `"Untuk mereset kata sandi, masukkan alamat email..."` |

## Format Penulisan di ARB
Setiap key **harus disertai** metadata `@key` dengan `description`:
```json
"btn_save": "Simpan",
"@btn_save": { "description": "Save button" },

"lbl_transactionDate": "Tanggal Transaksi",
"@lbl_transactionDate": { "description": "Transaction date label" },

"err_invalidEmail": "Alamat email tidak valid",
"@err_invalidEmail": { "description": "Invalid email error message" },

"desc_forgotPassword": "Untuk mereset kata sandi, masukkan alamat email yang Anda gunakan untuk login ke Luna. Link akan dikirim ke email Anda untuk mengatur ulang kata sandi",
"@desc_forgotPassword": { "description": "Forgot password instruction" }
```

Untuk string dengan **placeholder (interpolasi)**:
```json
"txt_totalItem": "Total ({count} items)",
"@txt_totalItem": {
  "description": "Total with item count",
  "placeholders": { "count": { "type": "int" } }
}
```
Dipanggil di Dart sebagai: `l10n.txt_totalItem(cartItems.length)`

Tipe placeholder yang valid: `String`, `int`, `double`, `DateTime`.

## Aturan saat Menambah String Baru
1. Tambahkan key baru ke **`lib/l10n/intl_id.arb`** (Bahasa Indonesia, wajib diisi).
2. Tambahkan key yang sama ke **`lib/l10n/intl_en.arb`** (Bahasa Inggris, terjemahkan).
3. Setiap key harus memiliki metadata `@key` beserta field `description`.
4. Jalankan `flutter gen-l10n` untuk meng-*generate* ulang `app_localizations.dart`.

## Penggunaan pada Widget
```dart
// Stateless
class MyWidget extends StatelessWidget {
  @override
  Widget build(BuildContext context) {
    final l10n = AppLocalizations.of(context)!;
    return ElevatedButton(
      onPressed: () {},
      child: Text(l10n.btn_save),
    );
  }
}

// Stateful
class _MyState extends State<MyWidget> {
  @override
  Widget build(BuildContext context) {
    final l10n = AppLocalizations.of(context)!;
    return Text(l10n.txt_welcomeBack);
  }
}
```
